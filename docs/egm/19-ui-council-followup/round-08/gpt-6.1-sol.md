Specific issues and improvements, ordered by importance:

1. **Git-specific actions are less discoverable.** The current panel hides them behind “Git metadata & project ID,” which sounds informational. Consider “Git details & actions” so users can better anticipate what expanding it provides.
2. **Path controls compete with reopening controls.** Every saved card now contains a bordered “Show full path” button alongside “Open.” Keep the consistent wording, but give path disclosure a lighter treatment to strengthen the main action.
3. **Saved-card layouts vary.** Duplicate titles have a folder line while the unique title does not; path buttons also shift horizontally with timestamp length. Use consistent metadata columns or alignment so scanning becomes more predictable.
