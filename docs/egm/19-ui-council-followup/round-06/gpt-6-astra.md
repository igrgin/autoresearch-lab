Specific issues and improvements, ordered by importance:

1. **Path controls still leave their exact action ambiguous.** “View project path” could mean revealing text or navigating somewhere; “View Git path” is less precise than the improved metadata heading. Use “Show full path” for disclosures and consistently identify `.git` utilities as metadata actions. Keep Finder navigation explicitly labeled.

2. **Success feedback is separated from the action’s destination.** The opening confirmation appears below “Where projects are saved,” away from the selected card and current-project heading. Place it immediately above the project list or near the current-project heading so the response is easier to associate with opening a project.

3. **The detail panel’s utility controls could be more orderly.** Long underlined labels and separately underlined chevrons make the project and Git sections visually busy. Use matching action rows with a single disclosure label and attached chevron, followed by a consistently aligned Copy control. Preserve the prominent Finder button and subordinate metadata action.
