Observed issues and improvements, in order of importance:

1. **The two path-copy actions are ambiguous.** “Project folder · Git repository root” suggests the paths are the same, yet “Copy project path” and “Copy Git path” appear separately. If they copy the same path, use one clearly labeled action; if they differ, identify what each copies.
2. **Duplicate projects still require close inspection.** The highlighted “-2” helps, but the distinguishing suffix is small. Give the differing portion more prominence or add another useful visible distinction, such as the full folder path when names repeat.
3. **Path disclosures are easy to miss.** “Show full path” sits low in each row in small text. Increase its prominence or show more of the path directly where space permits, especially for duplicate names.
4. **The creation panel’s folder label wraps awkwardly.** “Project folder · Git repository root” breaks across lines beside “Edit folder name.” Give the label more room or move the edit action below it for a cleaner grouping.
