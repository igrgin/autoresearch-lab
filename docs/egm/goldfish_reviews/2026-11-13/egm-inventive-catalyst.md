2. **Nit — User controls, closing, and recovery.**  
   **Dimension:** Contradiction Elimination & Inventive Transforms.  
   **Tension:** Autonomous remote progress versus reliable controller disappearance handling. If reconnection races with remote automatic pause, a resumed controller could otherwise launch another attempt before reconciling the completed one.

   **Secondary trade-offs:** Another component to install and update, durable remote state, and careful testing of recovery loops.  
   **IFR:** Controller loss changes supervision state without losing results or permitting duplicate exploration.

   **Dimension:** Contradiction Elimination & Inventive Transforms.  
   **Tension:** Comprehensive historical inspection versus limited model storage. A cleanup operation performed before result records are safely retained could leave an experiment visible but uninterpretable.  
   **Advice, not an approved requirement:** Explore **Segmentation** of durable experiment records from removable model blobs, with cleanup dependent on confirmed record preservation. This directly supports the agreed retention policy.  
   **Secondary trade-offs:** References between records and artifacts require consistency checks; failed transfers and partial cleanup need reconciliation.  
   **IFR:** Removing a non-winning checkpoint changes artifact availability while preserving meaningful experiment and run history.
