- **Functionality: 9/10.** Creation has one clear required field, an inspectable save location and a prominent action. Search, sorting and explicit Open buttons support finding and reopening projects. The reopened state clearly identifies the current project and provides a useful Finder action.
- **Appearance: 9/10.** Calm, cohesive styling with readable typography, restrained color and strong panel hierarchy. The current-project treatment is clear without overwhelming the list. Minor density and alignment issues remain.

Specific observed issues, ordered by importance:

1. **The creation panel’s path control has an ambiguous target.** “Show full path” follows the parent folder, while identically labeled buttons elsewhere refer to saved projects. Label this control “Show project path” and show the complete destination, including the new folder name.
2. **Saved-project metadata feels crowded horizontally.** Folder identifiers, path buttons and timestamps compete across each card, and button positions vary with identifier length. Give metadata a consistent arrangement and the path action a predictable position.
3. **The creation panel makes long paths awkward to read.** The parent path wraps across three lines, leaving “projects” isolated. A dedicated path block with clearer separation from the surrounding labels would improve scanning and polish.
