**Functionality: 7.5/10.** Creation and reopening have clear controls, and the reopened project gets a visible confirmation with its details. Finding a project may become cumbersome as the list grows, and the creation form leaves the relationship between project name and folder name unclear.

**Appearance: 8/10.** The interface is clean and consistent, with a clear hierarchy and readable controls. Generous card spacing and prominent filesystem paths make the list less compact and scannable than it could be.

Observed issues and improvements, in order of importance:

1. **Finding projects:** No search or sort control is visible. Add search by project name as the collection grows, and consider sorting by recent use.
2. **Creating a project:** The form does not explain whether the folder name is required, how it relates to the project name, or what names are valid. Suggest a folder name from the project name and add concise guidance or inline validation.
3. **Reopened project context:** The open-project card confirms the selection, but it sits between the creation form and saved list and offers no obvious project-specific action. Give the active project a stronger heading or status and make the next available action clear.
4. **List density:** Each project card devotes considerable space to a long path and a repeated “Ready to open” label. Use a more compact row or card, and make the path secondary or reveal it on demand.
5. **Refresh affordance:** “Refresh projects” reads like plain text compared with the other controls. Style it as a clear button, optionally with a refresh icon.
