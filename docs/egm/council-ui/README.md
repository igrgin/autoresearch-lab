## Delivered improvements

- One required project name, optional folder-name editing, and an inspectable save destination.
- Persistent navigation and saved-list/current-project panels, search, sorting and disposable local recency cues.
- Stable Current selection, explicit Open controls, and individual path inspection before opening.
- Catalog-validated Finder access and native clipboard actions for existing project/workspace paths.
- More readable labels, location grouping, action hierarchy and future-feature navigation.

The project creation/recovery storage invariants from issue 19 remain unchanged. No editor, repository import, dataset setup, provider integration or training capability was added.
