# Screenshot-only UI council

Each round uses three fresh T3 delegates (GPT Sol, GPT Astra and GPT Terra), at high reasoning effort. Reviewers receive the same brief, fixed grading rubric and current UI images only. They do not receive source, tests, prior scores, other reports or iteration history. Functionality scores assess visible interaction design; runtime behavior is checked separately.

The completion condition is every reviewer scoring functionality and appearance at least 9.5/10 in the same round. Raw prompts, inputs and responses are preserved in numbered round directories; implementation decisions and test evidence are recorded separately.
