- **Functionality: 9/10.** The core workflow is clear: enter a name to create, search or sort saved projects, and use explicit Open buttons to reopen them. The Current badge, highlighted row and “Project opened” panel provide strong visible feedback. Persistent navigation and Finder access make the next steps understandable.
- **Appearance: 8.8/10.** A cohesive, restrained design with readable typography, consistent controls and generous spacing. The list and contextual panel have a clear hierarchy. Awkward path wrapping and a little action-label ambiguity keep it short of fully polished.

Specific issues, ordered by importance:

1. **Paths are difficult to scan.** Both panels show long absolute paths wrapping mid-name; the creation destination splits “tabular-research” across lines. Give the destination folder its own prominent line, with the parent path secondary. Offer the full path through an explicit reveal/copy control.
2. **“Show details” overlaps with “Project details.”** The current row offers Show details while its panel is already visible, and that panel contains another collapsed Project details control. Use one consistent details interaction, or label the disclosure by its actual contents so the two actions are distinguishable.
3. **Future navigation still resembles active navigation.** “Coming later” communicates availability, but Runs and Compute retain the appearance of ordinary sidebar links. Make their unavailable state clearer through visibly disabled styling or compact “Soon” labels.
